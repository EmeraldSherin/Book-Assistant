# Voice Reader MVP

## Overview
Voice Reader MVP is an AI-powered application that converts PDF/EPUB books into speech and supports speech-to-text conversion.

## Features
- 📖 PDF to Audio (TTS)
- 📚 EPUB to Audio (TTS)
- 🎙️ Speech to Text (STT)
- 🌐 REST API with Flask
- 🔊 Output MP3 audio
